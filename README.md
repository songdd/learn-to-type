# 灵键打字 - 儿童打字练习平台
## 1 项目概述
灵键打字是一款专为儿童和打字初学者设计的互动式打字练习平台。通过趣味化的游戏形式（基础打字练习、小飞机射击、打地鼠），让用户在轻松愉快的氛围中掌握键盘指法，提升打字速度和准确率

## 2 三大核心模块
### 2.1 基础打字练习 (basictype.html)
循序渐进的字母练习模式，适合初学者建立指法基础。
特性	说明
关卡系统	52个关卡，从简单到复杂（基准键→上排键→下排键→数字键→全键盘）
难度分级	beginner（顺序练习）、intermediate（轻微打乱）、advanced（完全打乱）
实时反馈	正确/错误提示、准确率统计、计时功能
虚拟键盘	实时高亮当前需要按的键位，帮助记忆
通关奖励	完成关卡后星级评价（⭐⭐⭐ 100%准确率）

### 2.2 小飞机射击 (plane_shooter.html)

将打字与射击游戏结合，通过击落字母来得分。
特性	说明
游戏机制	按正确字母发射导弹击中目标
连击系统	连续命中得分递增（5连击15分，10连击25分）
难度递进	30个关卡，字母下落速度随关卡提升
战机皮肤	5种战机外观可切换
全屏支持	双击/Alt+Enter全屏，空格暂停

### 2.3 打地鼠 (whackamole.html)

地鼠举着字母牌子出现，按正确字母击打。
特性	说明
核心玩法	按字母键打击对应字母的地鼠
皮肤系统	5种小动物皮肤（老鼠/仓鼠/兔子/小猫/狐狸）
难度参数	rate控制地鼠停留时间，num控制目标数量
历史记录	保存每关最高分、最大连击、完成时间
飞锤特效	按键时锤子飞向目标地鼠
